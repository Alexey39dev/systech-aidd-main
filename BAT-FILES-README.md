# Bat файлы для запуска Systech AI Assistant

## Описание

Набор bat файлов для удобного запуска и управления сервисами Systech AI Assistant с Chat.

## Файлы

### 1. start-chat.bat
**Запуск всех сервисов**

- Запускает Backend API через `make run-api`
- Запускает Frontend через `npm run dev`
- Открывает два окна командной строки
- Автоматически ждет запуска backend перед frontend

**Использование:**
```bash
start-chat.bat
```

### 2. stop-chat.bat
**Остановка всех сервисов**

- Останавливает все процессы на портах 3000, 8000, 8001, 8002
- Безопасно завершает все связанные процессы
- Показывает статус остановки

**Использование:**
```bash
stop-chat.bat
```

### 3. test-chat.bat
**Тестирование сервисов**

- Проверяет доступность Backend API
- Тестирует Chat API endpoint
- Проверяет доступность Frontend
- Показывает результаты тестов

**Использование:**
```bash
test-chat.bat
```

## Преимущества

### ✅ Надежность
- Использует стандартные команды проекта (`make run-api`, `npm run dev`)
- Автоматически находит правильные пути к исполняемым файлам
- Работает независимо от установки Node.js в PATH

### ✅ Удобство
- Один клик для запуска всех сервисов
- Автоматическое ожидание запуска backend
- Отдельные окна для каждого сервиса
- Простая остановка всех процессов

### ✅ Кроссплатформенность
- Работает на Windows
- Использует стандартные команды, которые работают везде
- Легко адаптируется для Linux/macOS

## Требования

- **Python 3.8+** с установленными зависимостями
- **Node.js** (установлен в `C:\Program Files\nodejs\`)
- **Make** (для Windows можно использовать через Git Bash или WSL)
- **npm** (обычно идет с Node.js)

## Порты

- **3000** - Frontend (Next.js)
- **8000** - Backend API (FastAPI)
- **8001** - Backend API (альтернативный)
- **8002** - Backend API (debug)

## Устранение неполадок

### Backend не запускается
```bash
# Проверить зависимости
pip install -r requirements.txt

# Запустить вручную
make run-api
```

### Frontend не запускается
```bash
# Проверить зависимости
cd frontend
npm install

# Запустить вручную
npm run dev
```

### Порты заняты
```bash
# Остановить все сервисы
stop-chat.bat

# Или вручную
netstat -ano | findstr :3000
taskkill /f /pid <PID>
```

## Логи

Каждый сервис запускается в отдельном окне командной строки, где можно видеть:
- Логи запуска
- Ошибки
- Статус работы
- Запросы к API

## Автоматизация

Для автоматического запуска при старте системы можно:
1. Добавить `start-chat.bat` в автозагрузку Windows
2. Создать задачу в Планировщике заданий
3. Использовать как службу Windows
