# 🚀 Getting Started

> Быстрый старт: от установки до первого диалога за 15 минут

## Предварительные требования

- **Python 3.11+**
- **uv** — менеджер пакетов Python ([установка](#установка-uv))
- **OpenRouter API Key** — получить на [openrouter.ai](https://openrouter.ai)

---

## Шаг 1: Установка uv

### Windows
```powershell
winget install --id=astral-sh.uv -e
```

### macOS/Linux
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Проверка установки:
```bash
uv --version
# Должно показать версию, например: uv 0.4.0
```

---

## Шаг 2: Клонирование репозитория

```bash
git clone <repository-url>
cd systech-aidd-main
```

---

## Шаг 3: Установка зависимостей

```bash
make install
```

Эта команда:
1. Создаст виртуальное окружение (`.venv`)
2. Установит основные зависимости (`openai`, `pydantic`, `structlog` и др.)
3. Установит dev зависимости (`pytest`, `ruff`, `mypy`)

---

## Шаг 4: Настройка конфигурации

### 4.1 Создать файл `.env`

```bash
cp .env.example .env
```

### 4.2 Добавить API ключ

Откройте `.env` в редакторе и добавьте ваш ключ:

```env
# Обязательный параметр
OPENROUTER_API_KEY=sk-or-v1-ваш-ключ-здесь

# Опциональные параметры (можно оставить по умолчанию)
SYSTEM_PROMPT_FILE=prompts/default.txt
MAX_HISTORY=10
LLM_MODEL=openai/gpt-3.5-turbo
LLM_TEMPERATURE=0.7
LLM_MAX_TOKENS=1000
LOG_LEVEL=INFO
LOG_TO_FILE=false
LOG_COLORFUL=true
```

> **Где взять API ключ?**  
> 1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai)  
> 2. Пополните баланс ($5 достаточно для начала)  
> 3. Скопируйте ключ из раздела "API Keys"

## ❓ Частые проблемы

### Проблема: `uv: command not found`

**Решение:** Перезапустите терминал после установки uv или добавьте uv в PATH вручную.

---

### Проблема: `OPENROUTER_API_KEY not found`

**Решение:** 
1. Убедитесь, что создан файл `.env` (не `.env.example`)
2. Проверьте, что ключ указан в формате `OPENROUTER_API_KEY=sk-or-v1-...`
3. Нет пробелов вокруг `=`

---

### Проблема: `Rate limit exceeded`

**Решение:**
1. Проверьте баланс на [openrouter.ai](https://openrouter.ai)
2. Пополните счет
3. Приложение автоматически повторит запрос через несколько секунд

---

### Проблема: Тесты не проходят

**Решение:**
```bash
make clean   # Очистить кеши
make install # Переустановить зависимости
make test    # Запустить снова
```
