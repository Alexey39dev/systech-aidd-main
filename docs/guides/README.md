# 📚 Руководства по проекту

> Система гайдов для онбординга и работы с проектом

## 🎯 Для кого эти гайды

- **Новые разработчики** — быстрый старт и понимание проекта
- **Существующая команда** — справочник по архитектуре и процессам
- **Контрибьюторы** — как правильно вносить изменения

---

## 📖 Список гайдов

### 🚀 Быстрый старт (День 1)

1. **[Getting Started](01_getting_started.md)** ⏱️ 15 минут  
   Установка, настройка, первый запуск приложения

2. **[Обзор архитектуры](02_architecture_overview.md)** ⏱️ 30 минут  
   Компоненты, поток данных, принципы проектирования

3. **[Тур по кодовой базе](03_codebase_tour.md)** ⏱️ 45 минут  
   Обзор всех модулей, ключевые классы, карта зависимостей

### 💡 Углубленное изучение (День 2)

4. **[Модель данных](04_data_model.md)** ⏱️ 20 минут  
   Структуры данных, типизация, работа с историей диалога

5. **[Интеграции](05_integrations.md)** ⏱️ 20 минут  
   OpenRouter API, retry логика, система ролей

6. **[Конфигурация](06_configuration.md)** ⏱️ 15 минут  
   Переменные окружения, валидация, секреты

### 🔧 Разработка (День 3)

7. **[Процесс разработки](07_development_workflow.md)** ⏱️ 30 минут  
   TDD workflow, соглашения, чек-лист перед коммитом

8. **[Тестирование и качество](08_testing_and_quality.md)** ⏱️ 30 минут  
   Философия тестирования, инструменты, автоматизация

### 📊 Визуализация

9. **[Визуализация проекта](09_project_visualizations.md)** ⏱️ 30-45 минут  
   Диаграммы архитектуры, потоков данных, зависимостей (mermaid)

---

## 🗓️ Рекомендуемый путь онбординга

### День 1: Основы (1.5 часа)
```
Getting Started → Architecture → Codebase Tour
```
**Результат:** Проект запущен, архитектура понятна, код знаком

### День 2: Детали (1 час)
```
Data Model → Integrations → Configuration
```
**Результат:** Понимание данных, интеграций, настроек

### День 3: Практика (1 час)
```
Development Workflow → Testing & Quality
```
**Результат:** Готовность к первой задаче

### Опционально: Визуализация (30-45 минут)
```
Project Visualizations
```
**Результат:** Глубокое понимание архитектуры через диаграммы

## 🔗 Связь с другой документацией

### Гайды (вы здесь) vs Справочники

| Тип | Назначение | Примеры |
|-----|-----------|---------|
| **Гайды** | Практические how-to, пошаговые инструкции | Эта директория |
| **Справочники** | Детальная справочная информация | `vision.md`, `conventions.md` |
| **История** | Архив разработки | `tasklist.md`, `FINAL_REPORT.md` |

### Когда использовать что

- 🆕 **Новичок** → начни с гайдов (01-08)
- 🔍 **Нужна деталь** → смотри справочники (vision.md, conventions.md)
- 📝 **Вопрос "почему так?"** → история (tasklist.md, FINAL_REPORT.md)
