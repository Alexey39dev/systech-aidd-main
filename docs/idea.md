# Идея: Специализированный LLM-ассистент

## Описание проекта

Разработка специализированного LLM-ассистента с консольным интерфейсом, который выполняет **конкретную роль** через заданный системный промпт. Это не просто базовый чат-бот, а **полноценный AI-продукт** с четко определенной функцией и экспертизой.

### Концепция специализации

Ассистент **превращается в эксперта** в конкретной области через:
- **Файловый системный промпт** - роль и поведение задаются через отдельный файл промпта
- **Четкая функция** - ассистент специализируется на конкретной задаче (техподдержка, код-ревью, консультант и т.д.)
- **Экспертное поведение** - глубокие знания и специфичные ответы в своей области
- **Переключение ролей** - возможность менять роль через загрузку разных файлов промптов

## Основные характеристики

### Функциональность
- **Ведение диалога**: Приложение поддерживает естественное общение через консольный интерфейс
- **Ответы на вопросы**: Обработка и ответы на различные типы вопросов в рамках своей роли
- **Специализированная роль**: Системный промпт загружается из файла для определения роли/экспертизы ассистента
- **История диалога**: Поддержка контекста с сохранением истории сообщений
- **Управление ролью**: Команды для отображения и управления текущей ролью

### Техническая реализация
- **Интерфейс**: Консольное приложение с асинхронным вводом/выводом
- **Язык программирования**: Python 3.11+
- **LLM интеграция**: Подключение к OpenRouter API для доступа к различным моделям
- **Архитектура**: Модульная структура для легкого расширения функциональности
- **Менеджер пакетов**: uv для быстрой установки и управления зависимостями
- **Хранение промптов**: Отдельные файлы для системных промптов разных ролей

## Ключевые компоненты

1. **Console Interface (ConsoleApp)**
   - Обработка ввода пользователя
   - Управление состояниями диалога
   - Вывод ответов в консоль
   - Обработка команд:
     - `/help` - справка по командам
     - `/history` - история диалога
     - `/stats` - статистика диалога
     - `/clear` - очистка истории
     - `/role` - отображение текущей роли ассистента ⭐ **НОВОЕ**
     - `/exit` - выход из приложения

2. **LLM Integration (LLMClient)**
   - Подключение к OpenRouter API
   - Загрузка системных промптов из файлов ⭐ **НОВОЕ**
   - Обработка контекста диалога
   - Настройка параметров генерации

3. **Dialog Management (DialogManager)**
   - Сохранение истории диалогов в памяти
   - Управление контекстом разговора
   - Ограничение длины истории
   - Очистка истории по команде

4. **Configuration (Config)**
   - Путь к файлу системного промпта ⭐ **НОВОЕ**
   - Настройка роли ассистента через внешний файл
   - Конфигурация параметров LLM (модель, температура, токены)
   - Настройки логирования
   - Загрузка из .env файла

5. **Role Management** ⭐ **НОВОЕ**
   - Загрузка промптов из файлов (например, `prompts/support_agent.txt`)
   - Отображение текущей роли через команду `/role`
   - Валидация и применение роли при запуске
   - Возможность переключения ролей (будущее расширение)

## Преимущества реализации

- **Простота**: Минимальный интерфейс без лишних зависимостей
- **Скорость**: Быстрый запуск и отклик через консоль
- **Специализация**: Каждая роль оптимизирована под конкретную задачу ⭐ **НОВОЕ**
- **Гибкость**: Легкая настройка и смена роли через файлы промптов ⭐ **НОВОЕ**
- **Портативность**: Работает везде, где есть терминал
- **Интеграция**: Простое подключение к различным LLM через OpenRouter
- **Масштабируемость**: Легко добавлять новые роли через файлы

## Преимущества консольного интерфейса

- **Низкие требования**: Не требует графического интерфейса
- **Быстродействие**: Минимальные накладные расходы на интерфейс
- **Удобство для разработчиков**: Привычная среда работы
- **Скриптинг**: Легко интегрируется в скрипты и автоматизацию
- **SSH-доступ**: Возможность работы через удаленное подключение
- **Фокус на задаче**: Специализированная роль помогает сосредоточиться ⭐ **НОВОЕ**

```
prompts/

├── code_reviewer.txt        # Ревью кода
```

### Структура файла промпта

```txt
# Заголовок роли: [Название]
# Описание: [Краткое описание функции]

[Системный промпт с детальной инструкцией для LLM]
```

## Команда /role ⭐ **НОВОЕ**

### Функциональность
- **Отображение роли**: Показывает текущую активную роль ассистента
- **Описание функции**: Краткое описание, чем занимается ассистент
- **Источник промпта**: Путь к файлу промпта
- **Рекомендации**: Советы по эффективному использованию роли

### Пример вывода
```
Текущая роль: Технический ассистент
Описание: Эксперт технической поддержки для решения проблем
Источник: prompts/tech_support.txt
Специализация: Диагностика, инструкции, решение технических вопросов

Подсказка: Задавайте конкретные вопросы о технических проблемах для лучших результатов.
```
