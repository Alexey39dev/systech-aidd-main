## 📝 Структура тасклистов

Все тасклисты спринтов располагаются в папке `docs/tasklists/` и именуются по шаблону:

```
tasklist-<код_спринта>.md
```

**Примеры:**
- `tasklist-S000.md` - основной план спринта 0
- `tasklist_tech_dept-S000.md` - план устранения технического долга спринта 0
- `tasklist-S001.md` - основной план спринта 1 (персистентное хранение)
- `tasklist-S002.md` - основной план спринта 2 (управление пользователями)
