# Настройка проекта с UV

## 🎯 Что сделано

Проект настроен для работы с `uv` - современным быстрым менеджером пакетов Python от Astral.

1. **uv** - менеджер пакетов и виртуальных окружений
2. **Виртуальное окружение** - `.venv` с Python 3.11.9
3. **Все зависимости проекта:**
   - openai
   - pydantic + pydantic-settings
   - python-dotenv
   - structlog
   - pytest + pytest-asyncio

- Добавлены инструкции по установке `uv`

Скрипт для удобного запуска консольного приложения на Windows:
- Автоматически очищает проблемные переменные окружения Python

## 🚀 Как использовать

### Запуск приложения

Через Makefile:
```bash
make run
```

Через PowerShell скрипт:
```powershell
.\run.ps1
```

Напрямую:
```powershell
Remove-Item Env:\PYTHONHOME -ErrorAction SilentlyContinue
Remove-Item Env:\PYTHONPATH -ErrorAction SilentlyContinue
.\.venv\Scripts\python.exe -m src.main
```

### Команды приложения

После запуска доступны команды:
- `/help` - Показать справку
- `/clear` - Очистить историю диалога
- `/exit` - Выйти из приложения

### Установка зависимостей

```bash
make install
```

Или напрямую через uv:
```bash
uv venv --python 3.11
uv pip install -r requirements.txt
```

### Запуск тестов

```bash
make test
```

## ⚠️ Решенные проблемы

### Проблема с PYTHONHOME
На системе были установлены конфликтующие версии Python (стандартная и Anaconda).
Переменная окружения `PYTHONHOME` указывала на Anaconda, что приводило к ошибке:
```
ModuleNotFoundError: No module named 'encodings'
```

**Решение:** Скрипт `run.ps1` автоматически очищает `PYTHONHOME` и `PYTHONPATH` перед запуском.

### Переход с Telegram на консоль
Проект был переделан с Telegram-бота на консольное приложение:
- Удалён `bot.py` и все Telegram-зависимости
- Создан `console.py` для консольного интерфейса
- Обновлена вся документация

**Решение:** Консольный интерфейс работает стабильно и не требует внешних API.

### Выбор версии Python
Python 3.13 был поврежден, Python 3.11 имел конфликты с Anaconda.

**Решение:** Виртуальное окружение создано с Python 3.11 и изолировано от системных настроек.
