## 📊 Slide 14: Примеры улучшений (До/После)

### Пример 1: Глобальные переменные → ApplicationContext

**Было (проблема):**
```python
_app_instance = None  # Глобальная переменная

def handle_shutdown_signal(signum, frame):
    global _app_instance
    if _app_instance:
        _app_instance.stop()
```

**Стало (решение):**
```python
class ApplicationContext:
    def __init__(self):
        self.shutdown_event = asyncio.Event()
        self.logger = get_logger("app")
    
    def request_shutdown(self):
        self.shutdown_event.set()

def create_shutdown_handler(context):
    def handler(signum, frame):
        context.request_shutdown()
    return handler
```

**Выгоды:** ✅ Тестируемость, ✅ Чистота кода, ✅ SRP

---

### Пример 2: Generic исключения → Кастомная иерархия

**Было (проблема):**
```python
except Exception as e:
    logger.error(f"Error: {e}")
    return "Извините, произошла ошибка"
```

**Стало (решение):**
```python
except LLMRateLimitError as e:
    logger.error("Rate limit exceeded", details=e.details)
    await asyncio.sleep(e.retry_after)
    return await retry_request()
except LLMConnectionError as e:
    logger.error("Connection failed", details=e.details)
    return fallback_response()
```

**Выгоды:** ✅ Точная обработка, ✅ Диагностика, ✅ Retry логика

### Пример 3: Хардкод → Enum классы (DRY)

**Было (проблема):**
```python
print("Извините, произошла ошибка при обращении к сервису.")
# ... 20 строк спустя ...
print("Извините, произошла ошибка при обращении к сервису.")
# Дублирование в 5 местах!
```

**Стало (решение):**
```python
class ErrorMessages(str, Enum):
    LLM_ERROR = "Извините, произошла ошибка при обращении к сервису."

# Использование
print(ErrorMessages.LLM_ERROR.value)
```

**Выгоды:** ✅ DRY, ✅ Локализация, ✅ Type-safe, ✅ Легко менять

## 🎓 Slide 15: Извлеченные уроки

### 1. Инструменты качества критичны ⭐
- Ruff быстрее black + flake8 + isort
- Mypy strict ловит ошибки рано
- pytest-cov показывает пробелы
- **Вывод:** Автоматизация окупается

### 2. Тесты дают уверенность ⭐
- 149 тестов = защита от регрессии
- Параметризация экономит код
- Edge cases важны
- **Вывод:** Можно смело рефакторить

### 3. Типизация ловит ошибки ⭐
- TypedDict > dict[str, str]
- Literal ограничивает значения
- Mypy strict строгий, но полезный
- **Вывод:** Меньше багов в production

### 4. DRY не только про код ⭐
- Сообщения тоже централизуются
- Enum удобны для текстов
- Готовность к локализации бесплатно
- **Вывод:** Меньше дублирования

### 5. KISS важнее умности ⭐
- Простое решение лучше сложного
- Нет overengineering
- **Вывод:** Баланс качества и простоты
