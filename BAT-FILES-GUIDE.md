# Systech AI Assistant - Batch Files Guide

Этот документ описывает все доступные batch-файлы для управления сервисами Systech AI Assistant.

## Основные файлы

### 🚀 start-all.bat
**Запускает все сервисы (Backend + Frontend)**
- Запускает Backend API на порту 8000
- Запускает Frontend на порту 3000
- Доступны все функции: Dashboard + Chat
- **Рекомендуется для полной работы**

### 🛑 stop-all.bat
**Останавливает все сервисы**
- Останавливает все процессы на портах 3000, 8000, 8001, 8002
- Полная очистка всех сервисов

### 🔨 build-all.bat
**Собирает все сервисы для production**
- Устанавливает Python зависимости
- Устанавливает Frontend зависимости с pnpm
- Собирает Frontend для production
- **Используйте перед деплоем**

### 📦 install-all.bat
**Устанавливает все зависимости**
- Устанавливает Python зависимости с uv
- Устанавливает Frontend зависимости с pnpm
- **Используйте при первом запуске или после клонирования**

## Специализированные файлы

### 💬 start-chat.bat
**Запускает только чат**
- Запускает Backend API + Frontend
- Фокус на функциональности чата
- Для тестирования чата отдельно

### 🛑 stop-chat.bat
**Останавливает только чат**
- Останавливает процессы на портах 3000 и 8000
- Оставляет другие сервисы работать

### 📊 start-dashboard.bat
**Запускает только дашборд**
- Запускает Backend API + Frontend
- Фокус на функциональности дашборда
- Для тестирования дашборда отдельно

### 🧪 test-api.bat
**Тестирует API endpoints**
- Проверяет health endpoint
- Тестирует chat API
- Тестирует stats API
- **Для проверки работоспособности API**

## Порты и сервисы

| Порт | Сервис | Описание |
|------|--------|----------|
| 3000 | Frontend | Next.js приложение |
| 8000 | Backend API | FastAPI сервер |
| 8001 | Backend Alt | Альтернативный порт |
| 8002 | Backend Debug | Отладочный порт |

## URL-адреса

- **Главная страница**: http://localhost:3000
- **Дашборд**: http://localhost:3000/dashboard
- **Чат**: http://localhost:3000/chat
- **API документация**: http://localhost:8000/docs
- **API Health**: http://localhost:8000/health

## Рекомендуемый workflow

1. **Первый запуск**:
   ```bash
   install-all.bat  # Установка всех зависимостей
   start-all.bat    # Запуск всех сервисов
   ```

2. **Ежедневная работа**:
   ```bash
   start-all.bat    # Запуск всех сервисов
   # ... работа с приложением ...
   stop-all.bat     # Остановка всех сервисов
   ```

3. **Тестирование**:
   ```bash
   start-all.bat    # Запуск всех сервисов
   test-api.bat     # Тестирование API
   ```

4. **Разработка чата**:
   ```bash
   start-chat.bat   # Запуск только чата
   # ... разработка ...
   stop-chat.bat    # Остановка чата
   ```

5. **Подготовка к деплою**:
   ```bash
   build-all.bat    # Сборка всех сервисов для production
   ```

## Устранение проблем

### Порт занят
Если порт занят, используйте `stop-all.bat` для полной очистки.

### Ошибки сборки
1. Убедитесь, что установлены Node.js и Python
2. Запустите `build-all.bat` заново
3. Проверьте логи в открытых окнах командной строки

### API не отвечает
1. Запустите `test-api.bat` для диагностики
2. Проверьте, что Backend API запущен на порту 8000
3. Проверьте логи в окне "Backend API"

## Примечания

- Все batch-файлы можно запускать двойным кликом
- Окна командной строки остаются открытыми для просмотра логов
- Для остановки сервисов используйте соответствующие stop-файлы
- При разработке рекомендуется использовать специализированные файлы (start-chat.bat, start-dashboard.bat)
