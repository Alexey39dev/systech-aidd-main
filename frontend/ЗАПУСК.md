## Спринт FS-003 завершён! ✅

Дашборд статистики диалогов полностью реализован и готов к использованию.

## Требования

Для запуска проекта необходимо:

1. **Python 3.11+** с установленным `uv` - для Mock API
2. **Node.js 18+** с npm/pnpm/yarn - для Frontend

### Проверка установки:

```bash
# Проверка Python и uv
python --version
uv --version

# Проверка Node.js
node --version
npm --version
```

Если Node.js не установлен, скачайте с: https://nodejs.org/

## Быстрый запуск

### 1. Запуск Mock API (в первом терминале)

```bash
# Из корневой директории проекта
make run-api
```

Mock API будет доступно на: **http://localhost:8000**

### 2. Запуск Frontend (во втором терминале)

#### ⚠️ ВАЖНО: Сначала установите зависимости

Если зависимости не установлены или отсутствует `node_modules`:

```bash
cd frontend

# Используйте один из вариантов:
npm install        # если используете npm
# или
pnpm install      # если используете pnpm
# или  
yarn install      # если используете yarn
```

#### Запуск dev сервера:

**Вариант А: Через npm (стандартный способ)**

```bash
cd frontend
npm run dev
```

**Вариант Б: Через pnpm (если установлен)**

```bash
cd frontend
pnpm dev
```

**Вариант В: Через yarn (если установлен)**

```bash
cd frontend
yarn dev
```

**Вариант Г: Напрямую через node**

```bash
cd frontend
node node_modules/.bin/next dev
```

Frontend будет доступен на: **http://localhost:3000**

## Доступ к дашборду

Откройте в браузере: **http://localhost:3000/dashboard**

## Функциональность

### ✅ Реализовано:

1. **4 метрика-карточки**:
   - Total Dialogs (Всего диалогов)
   - Active Users (Активные пользователи)
   - Avg Dialog Length (Средняя длина диалога)
   - Messages Today (Сообщений сегодня)

2. **Timeline график**: Визуализация активности по времени

3. **Recent Dialogs**: Список последних 10 диалогов

4. **Top Users**: Топ 10 активных пользователей с визуальным выделением топ-3

5. **Фильтрация по периодам**:
   - Day (последние 24 часа)
   - Week (последние 7 дней)
   - Month (последние 30 дней)

6. **URL синхронизация**: Период сохраняется в URL (`?period=day`)

7. **Обработка состояний**:
   - Loading (Skeleton компоненты)
   - Error (с кнопкой Retry)
   - Empty states (пустые состояния)

## Устранение неполадок

### Проблема: "node: command not found"

**Причина**: Node.js не установлен или не добавлен в PATH

**Решение**:
1. Установите Node.js с официального сайта: https://nodejs.org/
2. Рекомендуется версия LTS (Long Term Support)
3. После установки перезапустите терминал
4. Проверьте установку: `node --version`

### Проблема: "pnpm: command not found"

**Причина**: pnpm не установлен глобально

**Решение 1** (рекомендуется): Используйте npm вместо pnpm
```bash
cd frontend
npm run dev
```

**Решение 2**: Установите pnpm глобально
```bash
npm install -g pnpm
```

### Проблема: "Port 3000 is already in use"

**Причина**: Порт 3000 занят другим процессом

**Решение**: Используйте другой порт
```bash
PORT=3001 npm run dev
```

### Проблема: "Failed to fetch stats"

**Причина**: Mock API не запущен или недоступен

**Решение**:
1. Проверьте, что Mock API запущен: `curl http://localhost:8000/health`
2. Запустите API: `make run-api`
3. Проверьте, что нет ошибок в логах API

### Проблема: Зависимости не установлены

**Причина**: Отсутствует `node_modules`

**Решение**:
```bash
cd frontend
rm -rf node_modules
npm install
```

### Проблема: Ошибки TypeScript при сборке

**Причина**: Несовместимость версий или неполные типы

**Решение**: Пропустите проверку типов в dev режиме
```bash
# В package.json измените dev скрипт:
"dev": "next dev --turbo"  # или используйте флаг --no-typescript
```

## Поддержка

При возникновении других проблем:

1. **Проверьте системные требования**:
   - Python 3.11+ для Mock API
   - Node.js 18+ для Frontend
   
2. **Проверьте порты**:
   - 8000 - Mock API
   - 3000 - Frontend
   
3. **Проверьте зависимости**:
   - Backend: `uv sync` в корне проекта
   - Frontend: `npm install` в директории frontend

4. **Проверьте логи**:
   - API логи в терминале с `make run-api`
   - Frontend логи в терминале с `npm run dev`
