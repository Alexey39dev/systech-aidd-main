## Как использовать

### Запуск дашборда

```bash
# Запуск Mock API
make run-api

# Запуск frontend
make run-frontend

# Дашборд доступен на http://localhost:3000/dashboard
```

### Функциональность

1. **Переключение периодов**: Используйте табы Day/Week/Month
2. **URL синхронизация**: Период сохраняется в URL (?period=day)
3. **Обновление данных**: Автоматическое при смене периода
4. **Обработка ошибок**: Кнопка Retry при ошибках API

## Известные ограничения MVP

В текущей версии **не реализовано**:

- Recharts график (используется упрощенная CSS версия)
- Real-time обновление данных
- Экспорт данных
- Детальный просмотр диалогов
- Кастомные временные диапазоны
- Анимации при изменении метрик
