### 2. API реализация

#### 2.1 Pydantic схемы ✅

- **Файл**: `src/api/schemas.py`
- **Модели**:
  - `MetricCard` - карточка с метрикой
  - `TimelinePoint` - точка данных для графика
  - `RecentDialog` - информация о диалоге
  - `TopUser` - информация о топ пользователе
  - `StatsResponse` - полный ответ API
- **Валидация**: Pydantic v2 с полной валидацией полей

#### 2.2 StatCollector интерфейс ✅

- **Файл**: `src/api/stat_collector.py`
- **Архитектура**: Абстрактный базовый класс для легкого переключения между Mock и Real реализациями

#### 2.3 MockStatCollector реализация ✅

- **Файл**: `src/api/mock_stat_collector.py`
- **Особенности**:
  - Генерация 50-70 реалистичных пользователей
  - Генерация 1000-1500 сообщений за последние 30 дней
  - Распределение ролей: 40% user, 40% assistant, 20% system
  - Расчёт метрик с процентными изменениями и трендами
  - Гибкая детализация timeline (почасовая для day, ежедневная для week/month)

#### 2.4 FastAPI приложение ✅

- **Файл**: `src/api/app.py`
- **Endpoints**:
  - `GET /` - информация об API
  - `GET /api/stats` - получение статистики
  - `GET /health` - health check
  - `GET /docs` - Swagger UI
  - `GET /redoc` - ReDoc документация
- **Настройки**:
  - CORS middleware для работы с фронтендом
  - Автогенерация OpenAPI документации
  - Обработка ошибок и валидация

#### 2.5 Entrypoint ✅

- **Файл**: `src/api/main.py`
- **Функциональность**: Запуск uvicorn с конфигурацией из Config

#### 2.6 Конфигурация ✅

- **Файл**: `src/config.py`
- **Добавленные параметры**:
  - `api_host` - хост API сервера (default: 0.0.0.0)
  - `api_port` - порт API сервера (default: 8000)
  - `api_reload` - автоперезагрузка (default: True)
  - `stat_collector_type` - тип сборщика (mock/real)

## Как использовать

### Запуск API

```bash
# Установка зависимостей
make install

# Запуск API сервера
make run-api

# API доступно на http://localhost:8000
# Документация на http://localhost:8000/docs
```

### Тестирование

```bash
# Тестирование через curl
make test-api

# Запуск автотестов
make test

# Открытие документации
make api-docs
```

### Примеры запросов

```bash
# Получить статистику за день
curl http://localhost:8000/api/stats?period=day

# Получить статистику за неделю
curl http://localhost:8000/api/stats?period=week

# Получить статистику за месяц
curl http://localhost:8000/api/stats?period=month
```
