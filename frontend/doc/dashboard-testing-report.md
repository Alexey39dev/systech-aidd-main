## Исправленные ошибки

### 1. ❌ → ✅ Ошибка `onValueChange` в компоненте Tabs

**Проблема**: 
```
[ERROR] Unknown event handler property `onValueChange`. It will be ignored.
```

**Причина**: Упрощенный компонент Tabs некорректно передавал props через cloneElement

**Решение**: 
- Создан `TabsContext` с React Context API
- Правильная организация передачи props через контекст
- Добавлены ARIA атрибуты для доступности (`role="tablist"`, `role="tab"`, `aria-selected`)

**Файл**: `frontend/components/ui/tabs.tsx`

**Статус**: ✅ Исправлено
