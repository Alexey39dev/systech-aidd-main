# Функциональные требования к дашборду статистики диалогов

## Обзор

Дашборд предоставляет визуальное представление статистики диалогов пользователей с AI-ассистентом. Дизайн основан на референсе: https://ui.shadcn.com/blocks#dashboard-01

## Основные компоненты

### 1. Метрика-карточки (Metrics Cards)

Четыре информационных блока с ключевыми показателями:

#### 1.1 Total Dialogs (Всего диалогов)

- **Описание**: Общее количество диалогов за выбранный период
- **Формат**: Целое число
- **Тренд**: Процентное изменение относительно предыдущего периода
- **Индикатор**: Стрелка вверх/вниз для визуализации тренда

#### 1.2 Active Users (Активные пользователи)

- **Описание**: Количество уникальных пользователей, отправивших хотя бы одно сообщение
- **Формат**: Целое число
- **Тренд**: Процентное изменение относительно предыдущего периода
- **Индикатор**: Стрелка вверх/вниз для визуализации тренда

#### 1.3 Avg Dialog Length (Средняя длина диалога)

- **Описание**: Среднее количество сообщений в диалоге (пара user + assistant)
- **Формат**: Число с одним десятичным знаком
- **Тренд**: Процентное изменение относительно предыдущего периода
- **Индикатор**: Стрелка вверх/вниз для визуализации тренда

#### 1.4 Messages Today (Сообщений сегодня)

- **Описание**: Количество сообщений за текущий день
- **Формат**: Целое число
- **Тренд**: Процентное изменение относительно вчерашнего дня
- **Индикатор**: Стрелка вверх/вниз для визуализации тренда

### 2. Timeline График (Activity Timeline)

Линейный график активности сообщений по времени.

**Характеристики:**

- **Ось X**: Временные метки (timestamp)
- **Ось Y**: Количество сообщений
- **Детализация**:
  - **Day (день)**: почасовая разбивка (24 точки данных)
  - **Week (неделя)**: ежедневная разбивка (7 точек данных)
  - **Month (месяц)**: ежедневная разбивка (30 точек данных)
- **Интерактивность**: Наведение курсора показывает точное значение
- **Визуализация**: Плавная линия с заливкой области под графиком

### 3. Recent Dialogs (Последние диалоги)

Список последних активных диалогов с детальной информацией.

**Отображаемые данные:**

- **Username**: Имя пользователя
- **Messages Count**: Количество сообщений в диалоге
- **Last Activity**: Время последнего сообщения (формат: "X minutes/hours ago" или точная дата)

**Характеристики:**

- Максимум 10 диалогов
- Сортировка по времени последней активности (от новых к старым)
- Компактное представление в виде списка

### 4. Top Users (Топ активных пользователей)

Рейтинг наиболее активных пользователей системы.

**Отображаемые данные:**

- **Username**: Имя пользователя
- **Messages Count**: Общее количество отправленных сообщений
- **Dialogs Count**: Количество диалогов пользователя

**Характеристики:**

- Топ 10 пользователей
- Сортировка по количеству сообщений (убывание)
- Визуальное выделение топ-3 пользователей

## Фильтрация по периоду

Дашборд поддерживает три периода просмотра:

### Day (День)

- Показывает данные за последние 24 часа
- Timeline: почасовая детализация
- Тренды: сравнение со вчерашним днем

### Week (Неделя)

- Показывает данные за последние 7 дней
- Timeline: ежедневная детализация
- Тренды: сравнение с предыдущей неделей

### Month (Месяц)

- Показывает данные за последние 30 дней
- Timeline: ежедневная детализация
- Тренды: сравнение с предыдущим месяцем

## Технические требования

### Производительность

- Загрузка дашборда: < 1 секунда
- Переключение периодов: < 500 мс
- Плавная анимация графиков

### Адаптивность

- Корректное отображение на экранах от 1024px
- Responsive layout для различных разрешений
- Оптимизация для десктопных браузеров

### Обновление данных

- Автоматическое обновление не требуется (MVP версия)
- Возможность ручного обновления через перезагрузку страницы или кнопку refresh

## Ограничения MVP версии

Для первой версии **не требуется**:

- Фильтрация по конкретным пользователям
- Экспорт данных
- Детальный просмотр отдельного диалога
- Настройка временных диапазонов (только предустановленные: day/week/month)
- Real-time обновление данных
- Drill-down функциональность
- Сравнение нескольких периодов

## Источник данных

На текущем этапе дашборд работает с **Mock API**, которое предоставляет тестовые данные для разработки и демонстрации UI. В будущих спринтах будет реализована интеграция с реальной базой данных.

## UI/UX принципы

1. **Простота**: Минималистичный интерфейс без избыточных элементов
2. **Читаемость**: Четкие метрики с крупными числами и понятными единицами измерения
3. **Консистентность**: Единообразное оформление карточек и элементов
4. **Визуальная иерархия**: Главные метрики в верхней части, детальная информация ниже
5. **Цветовая схема**: Нейтральная палитра с акцентами на важных элементах (тренды, топ пользователи)
