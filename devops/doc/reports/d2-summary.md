## Проблемы и решения

### 🔧 Решенные проблемы

1. **SSH ключ permissions (Windows)**
   - **Проблема:** "Permissions too open" для SSH ключа
   - **Решение:** Использование `icacls` для установки правильных прав
   - **Команда:** `icacls "key" /inheritance:r /grant:r "USER:RX"`

2. **PostgreSQL аутентификация**
   - **Проблема:** Ошибка подключения к БД
   - **Решение:** Добавлен `env_file` для PostgreSQL контейнера
   - **Файл:** `docker-compose.prod.yml`

3. **Frontend build ошибка**
   - **Проблема:** "Module not found: Can't resolve '@/lib/utils'"
   - **Решение:** Исправлен `.gitignore` и `Dockerfile.frontend`
   - **Детали:** Добавлен `frontend/lib/` в git, исправлен Dockerfile

4. **GitHub Actions build failure**
   - **Проблема:** Ошибки сборки из-за отсутствующих файлов
   - **Решение:** Исправлен `.gitignore` и `Dockerfile.frontend`
   - **Результат:** Образы пересобраны успешно
