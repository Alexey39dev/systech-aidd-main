## Обзор

Проведено полное тестирование локального запуска всех сервисов через docker-compose. Цель: убедиться, что все 4 сервиса (PostgreSQL, Bot, API, Frontend) запускаются одной командой и работают корректно.

## Команды для запуска

```bash
# Создание .env файла
cp .env.example .env

# Запуск всех сервисов
docker-compose up -d

# Проверка статуса
docker-compose ps

# Просмотр логов
docker-compose logs [service_name]
```
